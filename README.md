# AImage

This project is a machine learning program that determines whether a user inputted image is AI generated or not. It populates it's SQLite database by pulling a .csv from the Kaggle project and uploading each item into the database. It's backend is in Python. The front end is in Javascript and uses the ipywidgets library to connect with Jupyter Notebook. It uses a Convolutional Neural Network for the machine learning algorithm. 

It uses this Kaggle database: https://www.kaggle.com/datasets/alessandrasala79/ai-vs-human-generated-dataset.
